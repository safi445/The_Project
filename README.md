# SmartBarber: AI-Powered Barber Consultation Tool

SmartBarber is a professional consultation app designed to solve the biggest daily problem in barbershops: customers not knowing what style suits them.

## 🚀 Core Promise: See it. Like it. Cut it. No regrets.

The app uses your phone’s camera and advanced AI to scan a customer’s face in under 3 seconds, detecting key features like face shape, jawline, and hair density to provide instant, professional style recommendations.

## ✨ Key Features

### 1. AI Face Analysis
Instantly detects:
- **Face Shape**: Oval, Round, Square, Heart, or Diamond.
- **Jawline Type**: Sharp or Soft.
- **Hair Density & Patterns**: Optimizes recommendations for the best result.

### 2. Live AR Try-on
The centerpiece of the experience. Customers can see different haircuts and beard styles overlaid on their own face in real-time. This eliminates guesswork and "up to you" moments.

### 3. Smart Recommendation Engine
Suggests 3-4 professional combinations (haircut + beard) proven to suit the detected face type, based on barbering rules and current trends.

### 4. Barber Cut Sheet
Generates a precise technical sheet for the barber:
- **Fade Length**: Exact guard sizes (e.g., 1.5mm to 3mm).
- **Top Texture**: Styling instructions (e.g., matte clay, messy crop).
- **Beard Guide**: Length in mm and line-up instructions.

### 5. Style Memory & Maintenance
- **History**: Tracks each client’s past cuts for easy re-ordering.
- **Smart Reminders**: Automated WhatsApp links for maintenance touch-ups (e.g., "Your fade needs a refresh in 10 days").
- **Product Upsells**: Recommends specific clays or oils based on the selected style.

## 💼 Business ROI
- **Saves 5 minutes** of consultation per client.
- **Increases volume**: 20 clients/day = 100 mins saved (3-4 extra cuts).
- **ROI in 2 days**: Priced at Rs 2000/month per shop.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **AI/Vision**: MediaPipe Face Mesh, TensorFlow.js
- **Persistence**: LocalStorage (Offline-ready)

## 🔒 Security & Privacy
- **Client-Side Processing**: Face scanning happens locally on the device.
- **Privacy First**: No biometric data is stored on external servers.
- **CSP Protected**: Strict Content Security Policy for external assets.

## 📖 How to Use
1. **Open the App** on any mobile-friendly browser.
2. **Scan Face**: Position the client in the frame and tap "Scan Face".
3. **Try Styles**: Select from recommendations to see them live on the AR overlay.
4. **Finalize**: Review the Cut Sheet with the barber and save the style to history.
5. **After-Care**: Use the "Set Reminder" to keep the client coming back.
